I created how keylogger work. How they saved the data inside the text file. When makes a window with Start, Stop, Save, and Clear buttons plus a text box.
When you hit Start, it records every key you type in that box, each with a timestamp, into a list.
Save Log writes those keystrokes to a .txt file, and Clear wipes them.
User want to take care while creating the keylogger he/she does not want to enter the original text like (Password, OTP, UPI ID, etc.)
